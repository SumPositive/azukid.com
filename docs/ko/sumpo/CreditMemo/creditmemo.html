Deferin 사용 설명서

후일 결제 확인 앱

Deferin은 나중에 계좌에서 인출되는 지출을 관리하는 앱입니다. 신용카드 사용, 신용 연동 간편결제 충전, N일 후 인출, 지정일 인출 등 후불 결제 수단을 대상으로 합니다. 즉시 인출되는 체크카드 결제나 현금 충전처럼 그 자리에서 정산이 끝나는 결제는 대상이 아닙니다.

기본 흐름

1 결제 기록

금액을 입력하고 필요하면 라벨이나 태그를 추가합니다.

2 결제 수단 선택

인출 일정을 결정하는 카드나 후불 결제 수단을 선택합니다.

3 인출 확인

미결제와 결제 완료를 확인하고 계좌별로 예정된 인출을 살펴봅니다.

4 수정 또는 백업

필요하면 이력을 수정하거나 JSON으로 내보내 백업합니다.

⚠️ 데이터는 암호화되지 않습니다. 개인정보나 비밀정보를 입력하지 마세요.

기능

음성으로 새 결제금액과 라벨을 말하면 내역이 만들어집니다. 이어서 결제 수단도 말로 지정할 수 있습니다.
Siri 음성 입력“Hey Siri, Deferin에서 음성 입력”이라고 말하면 앱이 열리고 음성 입력이 시작됩니다.
색상 프리셋 12종인출 상태와 메뉴 아이콘의 배색을 12종에서 고를 수 있습니다. 앱 아이콘에도 반영됩니다.
새 결제를 빠르게 입력금액만 먼저 입력해 저장하고, 나머지는 나중에 채울 수 있습니다.
자주 쓰는 결제로 자동 입력자주 쓰는 라벨을 고르면 결제 수단과 태그가 채워집니다. 같은 금액을 3회 이상 사용한 라벨은 금액도 함께 채워집니다.
이력을 나중에 수정저장한 내역을 열어 라벨·태그·결제 수단·계좌를 변경할 수 있습니다.
예정된 인출 확인가까운 인출 합계를 보고 미결제와 결제 완료를 전환할 수 있습니다.
계좌별 집계인출일이 같아도 계좌별로 나누어 파악할 수 있습니다.
결제 일정 관리마감일/결제일 방식과 N일 후 방식을 모두 지원합니다.
태그 여러 개 지정전문가 모드에서는 여러 태그 지정과 태그별 정리가 가능합니다.
JSON으로 백업백업이나 다른 기기로 이전할 때 사용합니다.
표시 방식 조정글자 크기, 시작 시 화면, 저장 후 동작 등을 설정할 수 있습니다.

화면 구성

음성으로 새 결제 마이크로 내역을 만듭니다. 먼저 금액과 라벨을 말하고, 필요하면 결제 수단도 말로 지정할 수 있습니다. 인식된 수단은 탭해서 목록에서 다시 고를 수 있습니다. “Hey Siri, Deferin에서 음성 입력”으로 실행할 수도 있습니다.
새 결제 새 결제 내역을 입력합니다. 앱을 열 때 이 화면이 자동으로 열리도록 설정할 수 있습니다.
이력 저장된 내역을 봅니다. 대상 기간, 미입력 항목, 결제 수단, 계좌, 여러 태그로 걸러내고 날짜나 금액으로 정렬할 수 있습니다.
인출 상태 인출 예정과 인출 완료를 함께 표시합니다. 날짜·결제 수단·계좌 집계를 전환하고 수단이나 계좌로 걸러낼 수 있습니다.
결제 수단 카드 이름이나 후불 수단, 마감일/결제일, 인출 계좌를 등록합니다.
인출 계좌 인출되는 계좌 이름을 관리합니다. 결제 수단별로 연결할 수 있습니다.
태그 내역을 분류하는 선택 항목입니다.
설정 표시 옵션, 저장 후 동작, 백업, 지원 링크입니다.

새 결제 입력하기

먼저 금액을 넣거나 자주 쓰는 결제를 골라 저장하세요. 나머지는 나중에 채울 수 있습니다. 초보자 모드에서는 이 흐름이 입력 화면에 직접 안내됩니다.

기본 항목

자주 쓰는 결제 자주 쓰는 결제가 금액 칸 위에 버튼으로 표시됩니다. 탭하면 라벨·결제 수단·태그가 한 번에 채워지고, 같은 금액을 3회 이상 사용한 라벨은 금액도 채워집니다. 다시 탭하면 해제됩니다. 핸들을 끌어 표시 줄 수를 바꿀 수 있습니다. 설정에서 “결제 목록에서 복사” 또는 “없음”으로 바꿀 수 있습니다.
금액 숫자 키패드로 입력합니다. 금액을 넣었거나 자주 쓰는 결제를 골랐으면 저장할 수 있습니다(금액이 없으면 나중에 채울 수 있는 임시 내역으로 저장됩니다).
사용일 달력에서 선택합니다. 나중의 인출일은 선택한 결제 수단에 따라 자동으로 계산됩니다.
결제 수단 카드나 다른 후불 수단을 고릅니다. 선택하지 않은 상태로 저장하고 나중에 이력에서 채울 수도 있습니다.
계좌 선택한 결제 수단에 연결된 계좌가 아직 없을 때만 표시됩니다.
라벨 가게나 용도 같은 짧은 메모입니다. 입력하는 동안 과거 라벨이 제안됩니다.

선택 항목

태그 전문가 모드에서 사용할 수 있습니다. 여러 개를 지정하고 나중에 변경할 수 있습니다.
반복 전문가 모드에서 일시불 내역에 사용할 수 있습니다. 결제 완료로 표시하면 다음 달 또는 주기의 복사본을 자동으로 만들 수 있습니다.
메모 내역과 함께 남기고 싶은 내용을 자유롭게 적을 수 있습니다.

비슷한 내역

기존 내역에서 복사 이력에서 금액이 같은 내역이나 최근 수정한 내역을 골라 새 결제로 복사할 수 있습니다. 결제 수단 목록에서 복사하거나, 인출 상태에서 인출일과 결제 수단을 복사할 수도 있습니다. 복사하면 금액도 함께 넘어옵니다. 복사로 만들어진 임시 내역은 탭해서 수정하고 저장하면 확정되며, 저장하지 않으면 자동으로 사라집니다.

인출일 — 자동 / 수동

자동 인출일은 사용일과 결제 수단(마감일 / 결제일 / 결제월, 또는 N일 후 방식)에서 자동으로 계산됩니다. 사용일이나 결제 수단을 바꾸면 자동으로 갱신됩니다.
수동 아이콘을 탭하면 그 시점의 날짜로 고정됩니다. 이후에는 사용일이나 결제 수단을 바꿔도 인출일이 움직이지 않습니다. 마감일을 놓친 결제를 다음 인출 주기로 옮길 때 편리합니다. 날짜를 탭해 달력에서 고르거나, “이전 / 다음 결제일” 버튼으로 한 주기씩 이동할 수 있습니다.
결제 완료 시 수동으로 고정 항목을 결제 완료로 표시하면 인출일이 자동으로 수동으로 바뀌어 고정되며, 이후 사용일이나 결제 수단을 바꿔도 움직이지 않습니다. 미결제로 되돌려도 고정 상태는 유지되지만, 아이콘을 탭해 자동으로 되돌릴 수 있습니다.
분할 결제 분할 횟수는 1~12회에서 고를 수 있습니다. 인출일은 회차별로 한 줄씩 표시되고, 자동/수동 아이콘은 모든 줄을 함께 전환합니다. 금액은 자동으로 나뉘며, 금액을 탭해 직접 조정하면 나머지 회차가 그에 맞게 바뀝니다. 뒤 회차의 날짜는 앞 회차보다 뒤여야 하므로, 앞 회차를 그보다 뒤로 옮기면 뒤 회차가 자동으로 다음 달로 밀립니다. 어느 회차가 결제 완료로 표시되면 남은 회차의 날짜 외의 항목(금액, 사용일, 결제 수단 등)은 읽기 전용이 됩니다.

이력 살펴보기

정렬 날짜나 금액으로 정렬합니다. 각 정렬은 내림차순과 오름차순을 전환할 수 있습니다.
필터 기간을 3개월, 1년, 3년, 전체에서 고를 수 있습니다. 또한 전체, 미입력 있음, 결제 수단, 계좌, 여러 태그로 걸러낼 수 있습니다. 미입력 있음은 결제 수단이나 라벨이 빠진 내역을 포함합니다.
수정 줄을 열어 수정하거나 삭제합니다. 이미 전액 결제된 내역은 금액·날짜·결제 수단 같은 핵심 항목이 잠깁니다.

인출 상태

인출 상태는 예정된 인출과 이미 인출된 항목을 한 흐름으로 보여줍니다. 계좌에서 인출을 확인했으면 화살표 아이콘으로 해당 계좌 그룹을 결제 완료로 옮기세요. 언제든 미결제로 되돌릴 수 있습니다.
미결제 구역 미결제 항목은 예정과 기한 초과 그룹으로 나뉩니다. 기한이 지난 항목이 있으면 전환 스위치가 나타납니다.
가까운 인출 합계 상단 메뉴에 설정한 인출 기간의 합계가 표시됩니다. 1~20일 또는 1개월을 고를 수 있습니다.
계좌별 그룹 인출일이 같아도 계좌가 다른 항목은 별도의 인출 그룹으로 처리됩니다. 날짜·결제 수단·계좌 집계를 전환할 수 있습니다.
필터 전체, 결제 수단, 계좌에서 고릅니다. 수단이나 계좌를 고르면 시간 흐름을 보기 쉽도록 집계가 날짜로 바뀝니다.
상세 인출 줄을 열면 해당 인출에 포함된 결제 수단별 구역과 원래 결제 내역을 확인할 수 있습니다.
항목 단위 조정 인출 상세에서는 항목 하나만 미결제와 결제 완료 사이로 옮길 수 있습니다. 마감일에 걸친 항목 하나만 다음에 인출될 때 사용합니다.
잠금 전환 인출 상세에는 항목별 잠금 전환도 있습니다. 예전 앱의 확인 체크 기능을 되살린 것으로, 체크 표시 대신 자물쇠 아이콘을 사용합니다. 잠긴 항목은 명세서나 통장과 이미 맞춰본 항목을 뜻합니다.

결제 수단 · 계좌 · 태그

결제 수단

대상 범위 나중에 계좌에서 인출되는 결제 수단만 등록하세요. 간편결제의 경우 신용 연동 사용과 충전은 대상이지만, 이미 충전된 잔액을 쓰는 것은 대상이 아닙니다.
일정 방식 마감일 / 결제일 또는 N일 후 중에서 고릅니다. 마감일이나 결제일로 월말도 지정할 수 있습니다.
연결 계좌 결제 수단마다 계좌 하나를 연결할 수 있습니다. 연결을 바꾸면 관련된 과거 청구와 인출 그룹이 다시 만들어져 예전 계좌 그룹이 남지 않습니다.
열어서 수정 결제 수단 목록에서 줄을 탭하면 수정 화면이 열립니다. 상태 확인은 인출 상태의 집계와 필터에서 합니다.

계좌와 태그

계좌 인출되는 계좌 이름을 저장합니다. 기본 제공 프리셋에서 시작할 수도 있습니다.
태그 태그마다 관련된 결제 내역 목록을 보여 주어 확인과 정리에 쓸 수 있습니다.

백업과 설정

JSON 백업

내보내기 모든 데이터를 JSON 파일로 내보냅니다. 보관용으로 압축 형식, 확인용으로 보기 쉬운 형식을 고를 수 있습니다.
가져오기 내보낸 JSON 파일을 가져옵니다. 같은 데이터를 다시 가져오면 중복이 생기지 않고 내역이 갱신됩니다. 청구와 인출의 결제 완료 상태도 복원됩니다.
오래된 데이터 정리 데이터베이스가 너무 커지면 설정에서 오래된 내역을 정리할 수 있습니다. 실제로는 3년 정도의 이력이 사용을 전제한 범위입니다.

표시와 동작

초보자 / 전문가 초보자 모드에서는 설명이 더 많이 표시됩니다.
글자 크기 자동은 iOS의 글자 크기 설정을 따릅니다.
시작 시 열기 앱을 실행하거나 다시 돌아왔을 때 자동으로 열 화면을 고릅니다: 아무것도 안 함, 주 화면, 음성으로 새 결제, 새 결제, 결제 목록(기본값은 아무것도 안 함). 수정하는 중에는 끼어들지 않습니다.
키패드 자동 표시 금액을 입력하지 않은 상태로 새 결제를 열면 숫자 키패드가 자동으로 열립니다. 설정에서 켜고 끌 수 있습니다.
음성 입력 사용 주 메뉴에 “음성으로 새 결제”를 표시할지 정합니다. 기기 언어가 음성 인식에서 지원될 때만 표시됩니다(기본값 켜짐).
색상 프리셋 인출 상태(미결제 / 확인 대기 / 결제 완료)와 메뉴 아이콘의 배색을 12종에서 고릅니다. 고른 프리셋은 앱 아이콘에도 적용되어 홈 화면에서도 같은 배색이 보입니다.
저장 후 동작 저장한 뒤 되돌아가기, 다음 입력을 위해 비우기, 날짜와 결제 수단 유지, 이력 표시 중에서 고릅니다.
설명서와 지원 설정에서 이 사용 설명서를 앱 안에서 열 수 있습니다. 지원 항목에는 팁과 보상형 동영상 광고도 있습니다.

플랫폼 iOS 18 이상
최대 금액 99,999,999

결제 방식 일시불 또는 1~12회 분할(무이자·수수료 없음 전제). 보너스 결제는 지원하지 않습니다
인출일 계산 마감일 / 결제월 / 결제일에서 자동으로 계산합니다. N일 후 방식 카드는 사용일 + N일입니다. 결제 수단을 고르지 않으면 인출일은 사용일과 같습니다
인출일 고정 항목마다 수동과 자동을 전환할 수 있습니다. 결제 완료로 표시한 항목은 자동으로 고정됩니다
반복 1~99개월. 결제 완료로 표시하면 다음 주기의 복사본이 자동으로 만들어집니다
태그 항목마다 여러 태그를 지정할 수 있습니다. 목록에서 필터와 집계에 사용됩니다
인출 합계 기간 최근 1~20일, 30, 35, 40, 50, 60일(기본값 15일)
데이터 저장 기기 안에만 저장(SwiftData). 클라우드 동기화는 없습니다. 기기 자체는 iCloud 백업으로 보관할 수 있습니다
백업 / 복원 설정에서 전체 데이터를 JSON으로 내보내기 / 가져오기(압축 또는 보기 쉬운 형식)
JSON 가져오기 방침 id 기준 병합(upsert). 기준 정보(계좌·결제 수단·태그), 내역, 결제 완료 상태, 인출일 고정을 복원합니다. 없는 배열 키는 지정하지 않은 것으로 보고 건너뜁니다. 저장이 중간에 실패하면 모든 변경이 되돌려져 데이터베이스가 일관된 상태로 유지됩니다
JSON 가져오기 정규화 분할 횟수는 허용 범위로 정규화되며, 범위를 벗어나면 일시불이 됩니다. N일 후 방식 카드는 결제월이 0으로 정규화됩니다. 분할 내역에서 직접 조정한 금액은 가져올 때 유지됩니다. 해석할 수 없는 금액은 0으로 가져오고 경고를 남깁니다
이전 데이터 이행 예전 Core Data 파일(AzCredit.sqlite)에서 자동으로 이행합니다. 실패하면 다음 실행 때 자동으로 다시 시도합니다. iCloud 복원 후 WAL/SHM이 없으면 자동으로 복구합니다
오래된 내역 정리 설정에서 지정한 연수보다 오래된 내역을 한꺼번에 삭제할 수 있습니다
개인정보 외부 서버로 데이터를 보내지 않습니다. 기기 안의 데이터베이스는 암호화되지 않으므로, 민감한 개인정보를 저장하지 않도록 설계되어 있습니다

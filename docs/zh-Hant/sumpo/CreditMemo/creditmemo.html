Deferin 使用說明

延後扣款確認 App

Deferin 用來追蹤日後才會從帳戶扣款的支出，涵蓋信用卡消費、綁定信用的電子錢包儲值、N 天後扣款、指定日扣款等延後付款方式。當場即時扣款的金融卡消費、現金儲值等已完成結算的付款不在範圍內。

基本流程

1 記錄消費

輸入金額，需要時再補上標籤或標記。

2 選擇支付方式

選擇決定扣款時程的卡片或延後付款方式。

3 確認扣款

查看未扣款與已扣款項目，並依帳戶檢視即將到來的扣款。

4 修改或備份

需要時修改紀錄，或匯出 JSON 進行備份。

⚠️ 資料不會加密，請勿存入個人資料或機密資訊。

功能

用語音新增消費說出金額與標籤即可建立明細，接著也能用語音指定支付方式。
用 Siri 語音輸入說「Hey Siri，在 Deferin 語音輸入」就能開啟 App 並開始語音輸入。
12 種配色扣款狀況與選單圖示的配色可從 12 種中選擇，App 圖示也會跟著改變。
快速輸入新消費先輸入金額存檔，其餘資訊可以之後再補。
用常用消費自動填入選擇常用標籤即可帶入支付方式與標記；同一金額用過三次以上的標籤也會一併帶入金額。
事後修改紀錄開啟已存明細，可更新標籤、標記、支付方式與帳戶。
確認即將到來的扣款檢視近期扣款總額，並在未扣款與已扣款之間切換。
依帳戶彙整即使扣款日相同，也會依銀行帳戶分開呈現。
管理扣款時程支援結帳日/付款日與 N 天後兩種方式。
可加上多個標記達人模式支援多重標記與依標記整理。
用 JSON 備份可用於備份或轉移到其他裝置。
調整顯示與行為可設定文字大小、開啟時的畫面、存檔後的動作等。

畫面結構

用語音新增消費 用麥克風建立明細。先說出金額與標籤，需要時再用語音指定支付方式。辨識到的支付方式可點按，從清單改選其他項目。也可以說「Hey Siri，在 Deferin 語音輸入」來啟動。
新增消費 輸入新的消費明細。也可設定為開啟 App 時自動顯示此畫面。
紀錄 列出已儲存的明細。可限定期間，依未填項目、支付方式、帳戶或多個標記篩選，並依日期或金額排序。
扣款狀況 將尚未扣款與已扣款一併顯示。可切換依日期、支付方式或帳戶彙整，並依支付方式或帳戶篩選。
支付方式 登錄卡片名稱或延後付款方式、結帳日/付款日與扣款帳戶。
扣款帳戶 管理扣款帳戶的名稱，可與各支付方式建立關聯。
標記 用來分類明細的選用項目。
設定 顯示選項、存檔後行為、備份與支援連結。

輸入新消費

先輸入金額，或選擇一筆常用消費，然後存檔即可。其餘資訊可以之後再補。新手模式會直接在輸入畫面說明這個流程。

基本欄位

常用消費 最常使用的消費會以按鈕顯示在金額欄上方。點一下即可同時帶入標籤、支付方式與標記；同一金額用過三次以上的標籤也會帶入金額。再點一下可取消。拖曳把手可改變顯示行數。在設定中可切換為「從消費清單複製」或「無」。
金額 以數字鍵盤輸入。只要輸入金額或選了常用消費就能存檔（若沒有金額，會存成之後可以補完的草稿）。
使用日期 從日曆選擇。日後的扣款日會依所選支付方式自動計算。
支付方式 選擇卡片或其他延後付款方式。也可以先不選擇就存檔，之後再從紀錄補上。
帳戶 僅在所選支付方式尚未關聯帳戶時顯示。
標籤 店名或用途等簡短說明。輸入時會提示過去使用過的標籤。

選用欄位

標記 達人模式可用。可指定多個標記，之後也能變更。
重複 達人模式中可用於一次付清的明細。標記為已扣款時，App 可自動建立下個月或下個週期的複本。
備註 可自由填寫想與明細一起保留的內容。

相似明細

從既有明細複製 可在紀錄中挑選金額相同或最近編輯過的明細，複製成新的消費。也能從支付方式清單複製，或從扣款狀況複製扣款日與支付方式。複製時金額也會一併帶入。複製產生的草稿在點按編輯並存檔後才會確定；若未存檔，草稿會自動消失。

扣款日 — 自動／手動

自動 扣款日會依使用日期與支付方式（結帳日／付款日／付款月，或 N 天後方式）自動計算。變更使用日期或支付方式時會自動更新。
手動 點按圖示即可將日期固定在當下的值。之後變更使用日期或支付方式時，扣款日都不會移動。適合把錯過結帳日的消費挪到下一個扣款週期。點按日期可從日曆選擇，或用「上一個／下一個付款日」按鈕依付款週期跳動。
標記已扣款時固定為手動 將項目標記為已扣款時，其扣款日會自動切換為手動並固定，之後變更使用日期或支付方式也不會移動。即使改回未扣款，固定狀態仍會保留，但可點按圖示切回自動。
分期付款 分期期數可選 1～12 期。扣款日會依每一期各列一行顯示，自動／手動圖示會一併切換所有行。金額會自動分攤；點按金額可手動調整，其餘各期會隨之更新。後一期的日期必須晚於前一期，若把前一期移到後一期之後，App 會自動將後續各期順延到下個月。一旦某一期被標記為已扣款，除了尚未扣款各期的日期以外的欄位（金額、使用日期、支付方式等）將變為唯讀。

檢視紀錄

排序 可依日期或金額排序，每種排序都能在遞減與遞增之間切換。
篩選 期間可選 3 個月、1 年、3 年或全部。也可依全部、有未填項目、支付方式、帳戶或多個標記篩選。「有未填項目」包含缺少支付方式或標籤的明細。
編輯 點開任一列即可編輯或刪除。若明細已全額扣款，金額、日期、支付方式等主要欄位會被鎖定。

扣款狀況

扣款狀況把即將到來的扣款與已完成的扣款整合在同一個流程。確認銀行已扣款後，用箭頭圖示將該帳戶群組移到已扣款。隨時都能移回未扣款。
未扣款區塊 未扣款項目分為即將到期與已逾期兩組。若有逾期項目，會出現切換控制項。
近期扣款總額 上方選單會顯示所設定扣款期間的總額，可選 1～20 天或 1 個月。
依帳戶分組 即使扣款日相同，關聯到不同帳戶的項目會視為不同的扣款群組。可切換依日期、支付方式或帳戶彙整。
篩選 可選全部、支付方式或帳戶。選定支付方式或帳戶後，彙整會切換為依日期，讓時間順序更容易閱讀。
明細 點開扣款列，可查看該筆扣款中依支付方式分區的內容與原始消費明細。
單筆調整 在扣款明細中可將單一項目在未扣款與已扣款之間移動。適用於只有一筆接近結帳日的項目要到下次才扣款的情況。
鎖定開關 扣款明細中也有各項目的鎖定開關。這是舊版 App 確認勾選功能的復刻，但改用鎖頭圖示而非勾號。已鎖定表示你已核對過對帳單或存摺。

支付方式、帳戶與標記

支付方式

適用範圍 只登錄日後會從銀行帳戶扣款的支付方式。以電子錢包為例，綁定信用的使用與儲值屬於範圍內，但花用已儲值的餘額則不在範圍內。
時程類型 可選結帳日／付款日或 N 天後。結帳日或付款日也可以設為月底。
關聯帳戶 每個支付方式可關聯一個帳戶。變更關聯時，相關的歷史帳單與扣款群組會重新建立，不會留下舊的帳戶群組。
點開編輯 在支付方式清單點按任一列即可開啟編輯畫面。狀態的檢視則透過扣款狀況的彙整與篩選進行。

帳戶與標記

帳戶 儲存扣款帳戶的名稱，也可以從內建範例開始建立。
標記 每個標記都能顯示相關的消費明細清單，方便檢視與整理。

備份與設定

JSON 備份

匯出 將所有資料匯出為 JSON 檔。可選精簡格式以節省空間，或選易讀格式方便檢視。
匯入 匯入先前匯出的 JSON 檔。重複匯入相同資料只會更新明細，不會產生重複。帳單與扣款的已扣款狀態也會一併還原。
整理舊資料 若資料庫過大，可在設定中整理較舊的明細。實務上約三年的紀錄是預設的運用範圍。

顯示與操作

新手／達人 新手模式會顯示較多說明。
文字大小 「自動」會依 iOS 的文字大小設定。
開啟時顯示 選擇啟動或返回 App 時自動開啟的畫面：不做任何事、主畫面、用語音新增消費、新增消費、消費清單（預設為不做任何事）。編輯途中不會被打斷。
自動顯示數字鍵盤 在尚未輸入金額的狀態開啟「新增消費」時，數字鍵盤會自動開啟。可在設定中開關。
使用語音輸入 設定主選單是否顯示「用語音新增消費」。僅在裝置語言支援語音辨識時才會顯示此選項（預設開啟）。
配色 可從 12 種配色中選擇扣款狀況（未扣款／待確認／已扣款）與選單圖示的配色。所選配色也會套用到 App 圖示，讓主畫面呈現相同色調。
存檔後動作 可選擇存檔後返回、清空以便繼續輸入、保留相同日期與支付方式，或顯示紀錄。
說明與支援 可從設定在 App 內開啟本使用說明。支援項目中也提供小技巧與獎勵式影片廣告。

基本規格

適用消費 日後才從帳戶扣款的消費（即時扣款的卡片與現金儲值不在範圍內）
平台 iOS 18 或以上
金額上限 99,999,999
日期範圍 2000-01-01 至 2100-12-31
標籤長度 最多 50 字
備註長度 最多 200 字
付款方式 一次付清或 1～12 期分期（假設無利息、無手續費）。不支援紅利分期
扣款日計算 依結帳日／付款月／付款日自動計算。N 天後方式的卡片為使用日期 + N 天。未選擇支付方式時，扣款日等於使用日期
扣款日固定 每個項目都能在手動與自動之間切換。標記為已扣款的項目會自動固定
重複 1 至 99 個月。標記為已扣款時會自動產生下個週期的複本
標記 每個項目可加多個標記，用於清單的篩選與彙總
扣款總額期間 近期 1 至 20 天，或 30、35、40、50、60 天（預設 15 天）
資料儲存 僅存於裝置內（SwiftData），不做雲端同步。裝置本身可透過 iCloud 備份保存
備份／還原 可從設定將全部資料以 JSON 匯出／匯入（精簡或易讀格式）
JSON 匯入原則 依 id 合併（upsert）。會還原主檔（帳戶、支付方式、標記）、明細、已扣款狀態與扣款日固定。缺少的陣列鍵視為未指定並跳過。若儲存中途失敗，所有變更都會回復，讓資料庫維持一致
JSON 匯入正規化 分期期數會正規化到允許範圍，超出範圍者視為一次付清。N 天後方式的卡片，付款月會正規化為 0。分期明細中手動調整過的金額在匯入時會保留。無法解析的金額會以 0 匯入並留下警告
舊資料轉移 自動從舊版 Core Data 檔（AzCredit.sqlite）轉移。失敗時下次啟動會自動重試。iCloud 還原後缺少 WAL/SHM 會自動修復
整理舊明細 可在設定中一次刪除超過指定年數的明細
隱私 不會將任何資料傳送到外部伺服器。裝置內的資料庫未加密，因此本 App 的設計原則是不存放敏感的個人資訊

モチメモ　取扱説明

持ち物リスト・荷造り準備アプリ

旅行・出張・イベント・趣味用品の持ち物をリスト化し、必要数や重量を確認しながら荷造りを整えるアプリです。

パックごとに、タグで自由に分ける「タグ式」と、グループで階層に分ける「グループ式」を選べます。

チェックリスト、共有、バックアップ、AI 提案機能を使って、忘れ物を減らし、準備の負担を軽くできます。

基本操作の流れ

1 パックを作る

旅行やイベントごとに、持ち物をまとめるパックを作成します。

2 アイテムを登録する

必要数、在庫数、重量などを入力し、タグを付けて分類します。

3 チェックする

準備状況を確認し、不足数や重量を見ながら荷造りします。

4 共有・保管する

必要に応じて、パックの書き出しやバックアップを行います。

⚠️ データは暗号化しないので、個人情報や秘密情報を入れないでください。
App Store エンドユーザー使用許諾契約 プライバシーポリシー 作者自己紹介: sumpo

Undo について

操作手間の最小化を目指しました。よくある 「確認」ダイアログはなく、編集後の 「保存」ボタンもありません。「削除」は確認なしに即削除します。

間違えたときは 「Undo ↩︎」 ボタンで前の状態に戻せます。最大 10 回前まで戻れます。Redo で取り消しを戻すことも可能です。

分類方式（タグ式・グループ式）

パックごとに分類方式を選べます。パック一覧でバッグのアイコンをタップして開く「パック編集」の 分類方式 で切り替えます。新しいパックはタグ式で始まります。

2 つの方式

タグ式 階層を作らずにアイテムを 1 つのリストに並べ、タグを付けてゆるやかに分類します。1 つのアイテムに複数のタグを付けられます。パックを開くと、すぐにアイテム縦覧が表示されます。パック一覧では、バッグの取っ手にタグがぶら下がったアイコンで示します。
グループ式 パック（バッグ）・グループ（ポーチ）・アイテム（物品）の 3 層で、きっちり分類します。アイテムは必ずどれか 1 つのグループに入ります。
切り替え いつでも切り替えられ、アイテムやタグは消えません。グループ式からタグ式に変えると、グループ名がタグとしてそのグループのアイテムに付きます。
タグ式グループ タグ式で追加したアイテムは「タグ式グループ」に入ります。グループ式に戻すと、このグループで見られます。

タグ

付ける・外す アイテム詳細のタグ欄で、タグを押すと付け外しできます。上の欄に入力して探し、見つからないときは「追加」で新しいタグとして付けられます。
名前の変更・削除 タグを長押しすると名前を変更でき、このパックで同じタグが付いたアイテムもまとめて変わります。長押し中に出るゴミ箱ボタンで、このパックのすべてのアイテムからそのタグを外せます。
一覧での表示 設定の「明細表示」を タグ付き か タグ・メモ付き にすると、一覧の各行にタグを表示します。

アイテム縦覧

パック内の全アイテムを、グループをまたいで 1 つの一覧で表示します。タグ式ではパックを開くとこの画面になり、グループ式ではグループ一覧画面下部の「アイテム縦覧」ボタンから開きます。出発前の最終チェックや荷物の見直しに便利です。

並べ替え

未 ✔︎ 順 未チェックのアイテムを先頭にまとめます。出発前の最終確認に最適です。
不足個数 在庫数が必要数に届いていないアイテムを不足量の多い順に表示します。
不足重量 不足分の重量（不足個数 × 単重）が大きい順に表示します。
在庫重量 現在の在庫重量（在庫数 × 単重）が大きい順に表示します。重量オーバー時の見直しに役立ちます。
昇順・降順 並べ替え条件の右のボタンで、昇順と降順を切り替えます。
並べ直し チェックや数量を変えても、行の位置はすぐには動きません。並びが古くなると並べ替え条件がグレーになり、タップすると並べ直します。

絞り込みと検索

タグ一覧 タグを選ぶと、そのタグのアイテムだけに絞り込みます。「タグなし」も選べます。下のハンドルを上下にドラッグすると、タグ一覧の高さを変えられます。
検索 タグと、アイテムの名称・メモを対象に、入力に合わせて絞り込みます。
合計重量（タグ式） 一覧の末尾に、表示中のアイテムの合計重量を表示します。タグで絞り込むと、そのタグのアイテムの合計になります。

操作

詳細編集 行をタップすると、アイテム詳細を開きます。
数量パネル 行の重量・数量の部分をタップすると吹き出しが開き、その場で個重量・在庫数・必要数を変えられます。メモとタグも確認できます。
追加（タグ式） 右上の ＋ ボタンか、一覧の末尾の「末尾に追加」でアイテムを追加できます。
まとめて操作（タグ式） 「まとめて操作」を押して行をタップで選び、「操作」から タグを付ける・タグを外す・他のパックへコピー・削除 をまとめて行えます。「表示中をすべて選択」で、絞り込んだ結果を一度に選べます。

数量入力

個重量・在庫数・必要数は、アイテム詳細の数量欄や、一覧の数量パネルで入力できます。

入力方法

ステッパ ＋・− ボタンで 1 ずつ増減します（初期設定）。
ダイアル ダイアルを左右にドラッグして値を増減します。アイテム詳細の数量欄の右上のボタンで、ステッパとダイアルを切り替えられます。
テンキー 数値をタップすると、画面下にテンキーが開き、直接入力できます。÷ × − ＋ の計算もでき、割り算の端数は四捨五入します。

ダイアル設定

開き方 ダイアル表示のとき、数量欄の右上に出る「ダイアル設定」から開きます。
スタイル Legacy / Midnight / Brass / Ocean / Shape / Varnia / Chrome / Hairline / Rubber の 9 種類から選べます。
感度プリセット Fine / Mild / Standard / Light / Fast の 5 段階から選べます。
詳細調整 ピッチ・スムージング・慣性開始速度をスライダーで細かく調整できます。

パック共有・バックアップ

書き出し

パック単体 パック画面のメニューから「書き出す」を選ぶと、そのパック 1 件を .packlin ファイルとして書き出せます。AirDrop・メール・メモアプリなど任意の方法で共有できます。
全パックまとめて 設定画面の「全パックを書き出す（バックアップ）」から、全パックを 1 つの .packlin ファイルとして書き出せます。機種変更やデータ保全にご利用ください。

読み込み

操作 設定画面の「パックを読み込む」からファイルを選択します。単体パックとバックアップのどちらも同じ操作で読み込めます。
重複の扱い バックアップ復元では ID が一致するパックを上書きします。単体パックの共有では名前が一致するパックを上書きします。一致しない場合は新規追加されます。
ファイル判別 拡張子ではなく JSON の内容で単体／バックアップを自動判別します。

パック公開

作成したパックをクラウドに保存して公開できます。公開したパックは他の利用者が閲覧・取り込みでき、便利な持ち物リストをみんなで共有できます。他の利用者が公開したパックを自分のパックとして取り込むこともできます。

⚠️ 公開したパックの内容は誰でも閲覧できます。個人情報や秘密情報は含めないでください。

公開する

操作 パック編集画面のメニューから「公開する」を選ぶと、そのパックをクラウドに保存して公開できます。公開時に表示する作者ニックネームを設定できます（空欄の場合は「匿名」で公開されます）。
再公開・取り消し 同じパックを再度公開すると内容が上書きされます。公開の取り消し（削除）は公開パック一覧の画面から行えます。
公開中の表示 公開中のパックは、一覧のバッグアイコンの下に「公開中」バッジが表示されます。

取り込む

操作 パックリストの画面から公開パック一覧を開き、気に入ったパックを自分のパックとして取り込めます。人気順・新着順の並べ替えとキーワード検索に対応しています。
広告について 公開パックの取り込みは、一定回数ごとにリワード広告の視聴をお願いしています（運営支援のため）。

iCloud バックアップ

AI 利用券やパック公開用の ID を iCloud に自動でバックアップします。iCloud を有効にしていれば、端末を交換しても利用券や公開状態が復元されます。ログインや個人情報の登録は不要です。

AI 生成（チャッピー）オプション

旅行先やイベントの目的を伝えると、AI がパックの内容を提案してくれます。提案されたパックはそのまま保存でき、あとから自由に編集できます。既存パックを AI に渡して修正を依頼することもできます。

1 回の生成につき AI 利用券 1 枚を使います。利用券がなくても、動画広告を視聴して依頼できます。

利用方法

新規作成 パックリスト右上の ✦ ボタンから「チャッピーに作ってもらう」を選択して起動します。
既存パック修正 パック編集画面の ✦ ボタンから「チャッピーに修正してもらう」を選択します。現在のパック内容が AI に渡され、追記・修正の依頼ができます。
要望テキスト 最大 1,000 文字。旅行先・日数・目的・季節など自由に記述してください。

依頼の方法

AI 利用券 お持ちの AI 利用券で依頼できます。残りの枚数はチャッピーの画面に表示されます。
広告視聴 利用券がないときは、チャッピーの画面から動画広告を視聴すると、利用券を使わずに依頼できます。

設定

表示

表示モード 初心者：ヘッダーに操作説明を表示します。達人：説明を省いてコンパクトに表示します。
外観モード システム：端末の設定に従います。ライト：常にライトモード。ダーク：常にダークモード。
明細表示 一覧の各行に何を出すかを選びます。1 行目はどれも名称・重量・数量です。タグ・メモ付き：2 行目にタグ、3 行目にメモ　タグ付き：2 行目にタグ　名称（重量・数量）：1 行目のみ　最小：1 行目のみで行間を詰める　極小：さらに詰める。タグやメモが空の行は表示しません。グループの行は、タグ・メモ付きのときだけメモを表示します。
文字サイズ ローガンフリー！　自動：システム設定の文字サイズに追従　標準／大／特大 から選択できます。

操作

新規追加位置 新しいアイテム・グループ・パックをリストの 先頭 または 末尾 に追加するか選べます。

重量

必要重量を表示 必要数ぶんの重量（必要数 × 単重）を表示します。
重量 1,000g から kg 表示 合計重量やアイテムの個重量が 1,000g 以上になると「1.0 kg」形式に切り替えます。入力は常に g です。

チェックと在庫の連動

チェック ON で在庫を満たす チェックをオンにしたとき、在庫数を必要数まで自動で増やします。
チェック OFF で在庫を 0 にする チェックをオフにしたとき、在庫数を 0 にリセットします。

データ構造

階層 Pack → Group → Item の 3 層構造。Item が最小単位です。
タグ Item に複数のタグを付けられます。タグ式のパックも内部では同じ 3 層構造で、タグ式で追加した Item は「タグ式グループ」に入ります。
Pack バッグ・リュック・トランク・倉庫など
Group ポーチ・ボックスなど、Pack 内の小分け
Item 個として扱う物品

体調メモ　取扱説明

体調記録アプリ

血圧・心拍・体温・体重などの体調データを記録して見返すアプリです。

測定タイミング（起床時・就寝前など）を時刻から自動で分類します。グラフ・統計・症状の図表を「分析」の3つのタブに自由に配置して変化を確認でき、Apple ヘルスケアアプリとの同期もできます。

症状メモでは、頭痛・肩こりなどの症状を発症時の環境や直前の状況と一緒に記録し、発症の傾向を見返せます。

基本操作の流れ

1 記録する

血圧・心拍・体温・体重など、必要な項目を入力します。頭痛などの症状は「症状」として記録します。

2 分析で見る

分析1〜3のタブで、1週間から1年まで期間を切り替えて変化を確認します。

3 配置を整える

グラフ・統計・症状の図表を、見たいタブに振り分けて並べ替えます。

4 出力・同期する

必要に応じて PDF・CSV・JSON 出力や Apple ヘルスケア同期を使います。

⚠️ データは暗号化しないので、個人情報や秘密情報を入れないでください。

仕様・諸元

記録項目と入力範囲

血圧（収縮期） 30〜300 mmHg
血圧（拡張期） 20〜200 mmHg
心拍数 10〜200 bpm
体温 31.0〜42.9 °C
体重 0.0〜200.0 kg
体脂肪率 0.0〜100.0 %
骨格筋率 0.0〜100.0 %

測定タイミング（自動分類）

分類方式 記録時刻に基づいて自動分類。各タイミングの時刻帯は設定でカスタマイズ可能。区分は最大8つで、名称・アイコン・色・並び順も変更できます。
タイミング種類
  • 起床時 — 起床後1時間以内（排尿後・朝食や服薬の前）
  • 安静時 — 朝・夜以外に、座って落ち着いた状態
  • 就寝前 — 就寝する直前
  • 不調時 — 体調がおかしいと感じたとき
  • 運動前 — 運動の開始前
2.9.0 より前から利用中の場合は、従来の区分（就寝時・運動後を含む）のまま変わりません。
デフォルト時間帯
  • 0〜2時：就寝前
  • 3〜7時：起床時
  • 8〜19時：安静時
  • 20〜23時：就寝前
不調時・運動前は時刻では割り当てず、記録するときに選びます。

グラフ

表示期間 1週間・1ヶ月・3ヶ月・6ヶ月・1年。「全ページで同じ期間を使う」をオンにすると分析1〜3の期間を共通にし、オフにするとページごとに選べます。2.9.0 より前から利用中の場合はオフで始まります
グラフ種類
  • 血圧（収縮期・拡張期）
  • 脈圧（収縮期 − 拡張期）
  • 心拍数
  • 体温
  • 体重
  • 体重変化量
  • 体脂肪率
  • 骨格筋率
  • BMI（身長設定が必要）
目標ライン 目標値を設定するとグラフに目標ラインと「目標」ラベルを表示
カスタマイズ 分析画面右上の「配置」または設定「分析」→「配置」で、図表ごとに分析1〜3・非表示を選び、並べ替え可能。平均血圧、体重移動平均などの補助グラフも個別に切り替え可能。

症状メモ

記録項目 症状・発症日時・終息日時・程度・環境・直前の状況・対処・メモ
程度 なし・軽い・中くらい・強い。「なし」は症状が出なかった記録として残り、発症の件数には数えません。
終息 発症した時点では終息をOFFのまま保存できます。治まったあと記録一覧の「砂時計」を押すと、その時刻が終息として入り、持続時間を表示します。
症状のプリセット
  • 肩こり
  • 腰痛
  • 頭痛
  • 倦怠感・だるさ
  • めまい
  • 腹痛
  • 鼻水・鼻づまり
  • 咳
  • 発熱
  • 不眠
直前の状況のプリセット
  • 寝不足
  • 疲れ・過労
  • ストレス
  • 画面の見過ぎ
  • 同じ姿勢
  • 冷え
  • お酒
  • 食べ過ぎ
  • 食事抜き
  • 生理
複数選択できます。未選択は「思い当たらない」として扱います。
対処のプリセット
  • 解熱鎮痛薬
  • 寝た
  • 安静にした
  • 温めた
  • 冷やした
  • 胃腸薬
  • 抗アレルギー薬
  • 入浴した
  • ストレッチ・体操
  • 受診した
複数選択できます。
タグの追加・編集 一覧にない症状・状況・対処は、名称を入力して追加できます。長押しで名称を変更できます。よく使うものほど上に並びます。
環境（屋外） 気温・湿度・気圧・24時間気圧差。日本国内では気象庁アメダスの観測値を取得できます（記録日時が現在から3時間以内。公開データは約9日分）。それ以外は手入力します。前回の取得から1時間以内に再取得するときは動画広告が表示されます。
環境（室内・端末） 室温・室内湿度は手入力。気圧計のある端末では、端末で測った現地の気圧を取得できます。
上限 直前の状況・対処は1件あたり各10個、タグの名称は20字、メモは200字

症状の分析

配置 初期状態では「分析3」に表示。図表の配置は変更可能
分析期間 1週間・1ヶ月・3ヶ月・6ヶ月・1年（発症カレンダーは期間によらず年・月・日でたどる）
図表
  • 発症カレンダー — 年・月・日の発症件数と最大程度を表示。日をタップするとその日の記録の詳細を表示
  • 発症の周期性 — 症状ごとに、前回の発症から次の発症までの間隔を点で表示し、4件以上の発症からおよその周期を推定
  • 発症と環境 — 記録がある環境項目ごとに、環境値の範囲別の発症件数を程度別に積み上げて表示
  • 発症と直前の状況 — 状況ごとの発症件数を程度別に表示。未選択（思い当たらない）の件数は白い棒で表示
数え方 発症日時で1件と数えます（日をまたいで終息した記録も発症日だけに数える）。程度「なし」は数えません。
注意 記録した範囲の集計です。原因や相関を示すものではありません。

Apple ヘルスケア連携

同期方向 書き込みのみ・読み込みのみ・双方向
同期タイミング 自動（保存・表示時）または手動（ボタン操作）
双方向同期 アプリで削除した記録が再取り込みされないよう、削除状態も反映
対応データ種 血圧・心拍数・体温・体重・体脂肪率（骨格筋率は非対応）

データ出力

形式 PDF・CSV（Excel 対応 UTF-8 BOM）・JSON
症状メモ PDF・CSV・JSON 出力に含まれます。出力対象は記録一覧の絞り込み（種別・区分・症状）に従います。設定の「全記録を書き出す」（JSON）には全記録が含まれます
設定のバックアップ 「全記録を書き出す」（JSON）には、表示・記録画面・グラフ・統計・分析の配置・身長・目標値の設定も含まれます。取り込むときに設定も復元するかを選べます。ヘルスケア連携など端末ごとの設定は含みません
取り込み 書き出した JSON を取り込むと、端末の内容に統合されます。同じ日時の記録はバックアップの内容で更新し、端末にだけある記録や、追加・名称変更した症状・状況・対処はそのまま残ります。バックアップした時点の状態に置き換えるものではありません

表示・操作設定

外観モード 自動・ライト・ダークから選択可能
文字サイズ システム設定の文字サイズに連動（Dynamic Type 対応）。「設定」→「画面表示と明るさ」→「テキストサイズを変更」で調整。さらに大きくするには「設定」→「アクセシビリティ」→「画面表示とテキストサイズ」→「さらに大きな文字」をオン
ダイアル設定 ダイアルのデザイン、回しやすさ、反応を調整可能

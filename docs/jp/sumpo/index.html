sumpo

シルバーモバイルエンジニア

iPhone3Gが登場した翌2009年から iOS/Androidアプリを作り続けているモバイルエンジニアです。

仕事ではお客様の要望に、趣味では自分の要望に応えてアプリを作ってきました。

2026年からは「自分とエンドユーザーの要望に応えるアプリ作り」を目指しています。これは、AIスタッフの増員と自動テストの拡充により実現できるようになってきました。ご要望は各アプリの「アプリを評価する」やこのサイトの「お問い合わせ」からお寄せください。

開発の歩み

2009 — はじまり

前年に iPhone 3G が日本に登場したのを機に、アプリを作ってみようと思い立ち中古 Mac mini を購入した。Xcode 3・Objective-C・Cocoa はすべて初めてで手探り状態だったが、「自分が使いたいものを作る」という動機だけで夢中になった。

Core Data の習得も兼ねて、最初のアプリを App Store に公開した。「自己満足でも世界中で 100 人くらいにはハマるはず」という軽い気持ちだったが、その見込みは良い意味で外れることになった。

2010 — 最初の公開

最初のリリースは予想以上の反響で、モチメモは各国からダウンロードされるようになった。続けてクレメモも公開し、どちらも着実にユーザーを獲得していった。

開発を続ける中で、Picker コンポーネントは入力専用だが出力にも応用できると気づいた。店のレジからレシートが出てくるようなドラム式電卓を思い描き、実装してみると思いどおりの動きになった。海外ユーザーに特に好評だったため、後に ドラタク ⇒ CalcRoll ⇒ Calclin（カルメモ）と改名している。

電卓アプリを作ると決めたとき「浮動小数点演算は使わない」ことも決めた。1998 年に自作した BCD 演算ライブラリ（SBCD/C++）をそのまま組み込み、0.1+0.2=0.3 が保証される演算エンジンとして初版から搭載していた。このライブラリは 2026 年に AZCalc として Swift Package 化されることになる。

2011–2012 — ダイアル UI の時代

iOS でスキューモーフィズム（立体的なリアルデザイン）が流行し始めた頃、クラシックなダイアル操作をリアルに再現した独自コントロール AZDial を開発した。ノブを回す感触をスクロールとタッチで表現したもので、このコントロールを活かしたアプリをいくつか制作した。このライブラリは 2026 年に AZDial として Swift Package 化されることになる。

2013–2024 — 沈黙の 12 年

個人アプリの更新が止まった 12 年。とはいえ何もしていなかったわけではない。趣味で培った技術が本業で通用することが分かってからは、モバイル開発の中心的な役割を任されるようになり、設計・監査・後進の育成と関わる範囲が広がっていった。個人で試してきたことが、そのまま仕事の引き出しになっていた時期だ。

その代わり、趣味として腰を据える時間も気力も残らなかった。App Store に並んだままのアプリは古びていったが、手を入れられないまま年が過ぎていった。

2025 — Swift 6 / SwiftUI への移行

Swift 6・SwiftUI に慣れるため CalcRoll の移植を開始した。旧コードはすべて Objective-C で書かれており、現代の Swift に書き直すのは一からの再設計に近かった。新規アプリとして審査に提出したところ「類似アプリあり、新規性なし」で却下——そりゃそうだ！旧アプリのアップデートとして再提出し、無事に審査を通過した。1998 年からの SBCD ライブラリは C++ のまま組み込み利用した。

きっかけは、長年使ってきた年齢早見アプリが更新されなくなり、元々欲しかった機能も足りなかったことだ。ならば自分で作るかと思い立ったところに、バイブコーディングで即席にどこまで作れるか試したいという動機が重なった。ここまでは既存アプリの刷新が続いたが、和暦年齢メモは初めて一行もコードを書かずに作った新規アプリになる。要件を文章で書き、Claude に詳細設計を生成させ、上がってきた設計をレビューして直させてから実装に入る。この手順だと実装が驚くほど素直に進み、初期実装1日・改修1日の計2日でほぼ完成域に届いた。設計を先に固めて人間がレビューするという昔から当たり前だった工程が、ノーコードでもそのまま効くと確認できた一本だ。
